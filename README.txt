NIGHTFALL: BLADE SURVIVOR — MOBILE WEB PROTOTYPE

This is a standalone HTML5 game prototype designed for iPhone Safari in portrait orientation.

HOW TO PLAY
- Tap “Enter the night”.
- Drag anywhere on the arena to move your hero.
- Your blade attacks enemies automatically.
- Collect glowing essence orbs to level up and choose upgrades.
- Avoid enemies and survive as long as possible.

RUN IT
Open index.html in a modern desktop browser for a quick local test.
For iPhone use, publish the folder to a static web host (for example, a private or public GitHub Pages repository) and open the resulting HTTPS URL in Safari. Use Safari's Share menu > Add to Home Screen to launch it in an app-like full-screen mode.

LIMITATIONS
- This is a browser game, not a signed native iOS app and not an App Store submission.
- The source has been generated here but not tested in Safari on a physical iPhone.
- Hosting requires an HTTPS URL; opening the ZIP itself on iPhone will not install the game.
